# APMA E4990 — Data Science Coursework Archive

This repository is an archived collection of coursework, notebooks, examples, and project material from **APMA E4990: Introduction to Data Science in Industry**.

It is preserved as a learning and reference repository rather than presented as an active research project.

## Topics represented

The repository includes material covering:

- supervised learning: regression and classification
- model selection and regularization
- unsupervised learning and clustering
- PCA and dimensionality reduction
- A/B testing and introductory causal inference
- recommendation systems
- Bayesian methods
- reinforcement learning
- introductory deep learning
- data engineering and API development

## Repository structure

- `homework/` — assignment notebooks and associated data
- `notebooks/` — instructional and exploratory notebooks
- `lectures/` — course lecture material
- `flaskapi/` — example Flask/scikit-learn prediction API
- `recengine/` — recommendation-engine material
- `webapp/` — web application examples
- `data/` — datasets used by notebooks and projects
- `final_project.md` — final-project material
- `html/`, `pdfs/`, `img/` — supporting course/export assets

## Note on provenance

Some instructional text and examples originate from course materials rather than from original research by the repository owner. The repository is retained to document training and technical development in applied machine learning and data science.

My current research focuses on computational materials physics, density-functional theory, superconductivity, RMTA/electron–phonon modeling, and machine-learning interatomic potentials. This repository represents earlier data-science training that supports that work.
